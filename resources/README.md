# 文化概念资源库（三层结构）

本目录只收录提示资源本身，不含生成图像、代码或核看记录。

## 结构

```
concepts/       概念记录 92 条
  01_概念记录_75条.csv          原词、原语言、中文名、英文转译、出处、释义等
  02_概念记录_新增第一批_9条.csv
  03_概念记录_新增第二批_5条.csv
  04_概念记录_新增第三批_3条.csv
practices/      实践／角色资源 9 条
  实践与角色资源_9条.csv        把概念含义转译为当代任务与角色关系
prompt_cards/   结构化提示卡 32 条，覆盖 16 个概念
  提示卡_第一批_24条.csv
  提示卡_第二批_8条.csv
```

## 三层

1. **记录层**：保存来源语义——原词、释义、出处、历史语境、核查状态，保证可追溯。
2. **实践层**：保存任务转译——每条概念对应可见的当代实践、工具与场景、参与角色。
3. **提示层**：保存生成条件——按七槽位 (C, R, T, I, H, E, S) 组织：
   C 概念含义 · R 角色 · T 任务与工具 · I 互动 · H 人格 · E 表情 · S 场景。

## 说明

- 所有字段为研究自建分类，编码表与锚点见论文正文。
- 概念与文献出处逐条保留，便于核看与复用。
